# Gestionale Concerti (Stile TicketOne)
Progetto per l'esame di Tecnologie Informatiche per il Web (TIW).

## Descrizione
L'applicazione permette agli utenti di acquistare e prenotare biglietti per concerti. Include funzionalità di integrazione con Google Calendar.

## Tecnologie utilizzate
* Java (Servlet / JSP)
* Tomcat 10.1
* Database MySQL

## Istruzioni per l'avvio
1. Assicurarsi di avere Tomcat 10+ configurato.
2. Importare il file `database.sql` (se ne hai uno) in MySQL per creare le tabelle necessarie.
3. Modificare le credenziali di connessione al DB nel file appropriato.
4. Avviare il progetto tramite IntelliJ o Maven.
